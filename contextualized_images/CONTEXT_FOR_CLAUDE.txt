Bloomfield CC Facebook Image Context Package
=====================================

Goal:
- Prioritize cricket-first storytelling for the website.
- Keep social/community images available, but secondary.

How images were sorted:
- Primary signal: caption sidecar files (*.jpg.caption.txt).
- Fallback signal: OCR text extracted from images where caption was empty/missing.
- Manual visual override: low-signal images were reviewed in contact sheets and reassigned.
- Classification was done with cricket/social/community keyword patterns plus manual corrections.

Folder priority for website building:
1) 01_cricket_matches_and_action (highest priority)
2) 02_cricket_player_profiles_and_awards
3) 03_cricket_team_and_tournament_announcements
4) 05_community_events_mixed (optional supporting content)
5) 04_social_entertainment_low_priority (use sparingly)
6) 06_unclear_needs_manual_review (check before publishing)

Counts by folder:
